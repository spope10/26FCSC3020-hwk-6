# Overview 

The goal of this assignment is to assess your understanding of how to design a use case diagram based on a given set of user requirements.

# Instructions

Create a UML use case diagram (using PlantUML syntax) for the following scenario:

A system is designed to help companies hire employees to fill job vacancies. The system should support the following features:

* Create job descriptions and generate a shareable link for posting on platforms like LinkedIn.
* Candidates apply by filling out a form and uploading documents such as CVs and letters of recommendation.
* A hiring committee evaluates all candidates.
* The system allows the committee to discard unqualified candidates, automatically sending them a rejection email.
* Remaining candidates are interviewed, and a hiring decision is made.
* The system can generate analytical reports for any completed hiring process.

Use the provided [scenario.wsd](scenario.wsd) file.
